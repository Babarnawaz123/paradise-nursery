# Paradise Nursery Shopping Application

Paradise Nursery is an e-commerce application built with React and Redux Toolkit that allows users to browse houseplants, add them to a shopping cart, and manage item quantities dynamically.

## Features

- **Landing Page**: Welcome banner with company details and quick navigation.
- **Product Catalog**: Houseplants grouped into Air Purifying, Aromatic, and Medicinal categories.
- **Redux State Management**: Dynamically tracks added items, unit prices, and overall total counts.
- **Interactive Cart**: Quantity adjustment (+/-), item deletion, and live cost calculation.

## Tech Stack

- React.js
- Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- Vite
- GitHub Pages
